# Фотографии набора

Фотографии в этом проекте — не украшение. По ним человек понимает, **что
он будет собирать** (карточки на главной) и **как должно выглядеть
собранное** (фото внутри урока). Поэтому кадр важнее красоты: видно ли
плату, макетку и провода целиком.

## Где они лежат и кто на них ссылается

```
assets/proj1-photo.jpg, proj2-assembled.jpg …   собранные проекты
assets/comp-01-arduino.jpg … comp-36-*.jpg      отдельные детали
assets/qr-telegram.png                           QR Telegram-группы
```

Ссылаются три места, и все три надо держать в согласии:

1. **`kit.js`, таблица `PHOTO`** — какой файл показывать на карточке
   проекта на главной и в верхнем блоке. Ключ — номер проекта.
2. **`course.html`** — внутри уроков, через `<image-slot src=…>` или
   `<img src=…>`. Это живой текст сайта; печатная книга в `архив/`
   заморожена, туда фотографии не переносить.
3. **`help.html`** — сейчас только QR.

Имена файлов не менять без нужды: они прописаны в трёх местах, и
переименование — это три синхронные правки. Проще положить новый файл под
старым именем.

## Требования к готовому файлу

- **Соотношение 4:3**, горизонтальный кадр. Карточка на главной обрезает
  под `aspect-ratio: 4/3` — если исходник другой, края уедут.
- **Ширина 1200 px** достаточно: на карточке фото показывается шириной
  около 300 px, в уроке — до 900. Больше — лишний вес.
- **Вес до 250 КБ** на снимок. Сейчас в папке разброс от 17 КБ до 355 КБ,
  вся папка 5,2 МБ — это загрузка сайта с телефона по мобильному
  интернету.
- **JPEG, качество 78–82.** Выше — не видно разницы, только вес.
- **Единый вид у всех семнадцати**: один фон, одно освещение, примерно
  один масштаб платы в кадре. Съёмку делает Максат; твоя работа — не
  дать разъехаться кадрам и размерам.

## Как обрабатывать

Работай питоном с Pillow, он есть в контейнере:

```python
from PIL import Image, ImageOps
im = ImageOps.exif_transpose(Image.open(src))   # развернуть по EXIF
im = ImageOps.fit(im, (1200, 900), Image.LANCZOS, centering=(0.5, 0.5))
im.convert('RGB').save(dst, 'JPEG', quality=80, optimize=True)
```

`ImageOps.fit` обрезает по центру. **Перед сохранением посмотри результат
Read'ом**: если центральная обрезка срезала плату или край макетки —
подбери `centering` вручную и покажи Максату два варианта на выбор.

После обработки всегда сообщай: старый вес → новый вес, старый размер →
новый размер, по каждому файлу.

  Пока стоит заглушка — не выдавать её за фото сборки в тексте.

## Чего не делать

- **Не ретушировать содержимое кадра**: не убирать провода, не
  подрисовывать светодиоды, не менять цвета деталей. Человек будет
  сверять своё с фотографией; расхождение дороже красоты.
- **Не поднимать резкость и контраст «чтобы красивее»** — на макетке это
  превращает провода в кашу.
- **Не класть в папку файлы, на которые никто не ссылается.** Каждый
  снимок в `assets/` должен быть кому-то нужен.
- **Не трогать `qr-telegram.png`** — это рабочий QR, пережатие может
  сделать его нечитаемым камерой.
