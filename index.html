Что такое
Arduino.

Маленькая плата зелёного или синего цвета размером примерно с банковскую карту, а на ней — крошечный чип, который работает как очень простой компьютер. У обычного компьютера есть экран, клавиатура и мышка, а у Arduino ничего этого нет — вместо этого по краям платы расположены ряды маленьких контактов (называются пины, подробно о них — в разделе 3.1), к которым подключаются провода, а через них — светодиоды, кнопки, моторы, датчики и экраны.

Как это работает

Ты пишешь на своём обычном компьютере программу — набор команд о том, что должна делать плата, — и одной кнопкой отправляешь её на Arduino по USB-кабелю. Плата запоминает программу и дальше выполняет её сама, даже без компьютера, если у неё есть отдельное питание (например, батарейка).

Это одновременно три вещи

Работая с Arduino, ты сразу тренируешь три разных навыка: программирование (пишешь код), электронику (собираешь схему из проводов и деталей) и физику (наблюдаешь, как электричество реально заставляет что-то происходить). Обычная программа на компьютере просто выводит текст на экран, а здесь результат кода можно увидеть, услышать или потрогать: загорелся светодиод, зажужжал моторчик, на экране появилась надпись.

Кому подходит

Детям и подросткам — как первые шаги в электронике, без страха что-то сломать.
Студентам — как практика к курсам по микроконтроллерам.
Взрослым новичкам — как хобби и способ понять, как устроены «умные» устройства вокруг.
Учителям и кружкам — как готовый комплект на 20+ занятий.

Два типа сигналов

Arduino умеет работать всего с двумя видами сигналов. Цифровой — это всегда либо «включено», либо «выключено», без всяких промежуточных состояний, как обычный выключатель света на стене: либо горит, либо нет. Используется для кнопок, светодиодов, реле.

Аналоговый — это любое значение в широком диапазоне (Arduino понимает его как число от 0 до 1023), как крутилка громкости на колонке: можно сделать чуть тише, чуть громче, а не только «вкл» или «выкл». Используется для потенциометров, фоторезисторов, датчиков температуры.

2.1 — Arduino IDE

Официальная бесплатная программа для написания и загрузки кода.

  1. Откройте arduino.cc/en/software
  2. Выберите версию для своей ОС (Windows / macOS / Linux)

2.2 — Подключение платы

В большинстве случаев драйверы уже поставились вместе с Arduino IDE (см. пункт 4 слева). Достаточно подключить плату — Windows подхватит её сама.

  1. Воткни USB-кабель в плату и в ноутбук
  2. На плате должны загореться светодиоды ON и L
  3. Открой Arduino IDE → меню «Инструменты» → «Порт»
  4. Если в списке появился COM-порт (COM3, COM5 и т.п.) — плата определилась, переходи к 2.3
!
Если COM-порта в списке нет — установи драйвер CH340. Скачай с официального сайта: wch-ic.com/downloads/CH341SER_EXE.html → кнопка Download → запусти CH341SER.EXE → INSTALL → дождись «Driver install success». Затем переподключи плату.

Используй USB-кабель из комплекта набора. Кабели «только для зарядки» (часто идут к наушникам и колонкам) не передают данные — питание будет, но компьютер плату не увидит.

2.3 — Настройка IDE

В разделе 2.2 ты уже воткнул плату и убедился, что COM-порт появился. Теперь покажем Arduino IDE, какая именно плата у тебя подключена.

  1. Открой Arduino IDE
  2. Сверху, между зелёными кнопками и панелью кода, найди выпадающий список «Select Board»
  3. Нажми на стрелку справа → выбери внизу «Select other board and port…»
  4. В левой колонке «BOARDS» в поиске напечатай Uno → выбери «Arduino Uno» (первый в списке, без R4 и без WiFi)
  5. В правой колонке «PORTS» выбери свой COM-порт (например, COM3)
  6. Нажми OK
i
✓ Всё настроено правильно, если: сверху IDE в выпадающем списке написано «Arduino UNO», а в правом нижнем углу — «Arduino UNO on COM3» с иконкой USB-вилки слева.

2.4 — Как вставлять и заливать код

В каждом проекте в разделе «Код» дан готовый текст программы (скетч). Чтобы он заработал, его нужно перенести в Arduino IDE и отправить на плату:

  1. Откройте Arduino IDE, кликните в окно редактора кода.
  2. Ctrl+A — выделить весь текст, Delete — очистить окно.
  3. Скопируйте код из инструкции и вставьте в IDE — Ctrl+V.
  4. Проверьте плату и порт вверху (например, «Arduino Uno on COM3»).
  5. Нажмите «→» (Upload) в левом верхнем углу — не галочку, она только проверяет код.
  6. Дождитесь «Done uploading» внизу окна — код на плате.
i
Пока не нажали Upload, на плате остаётся предыдущий код — даже если схема собрана правильно, поведение будет от старой программы.

Пины
и breadboard.

Прежде чем собирать первую схему, разберёмся с двумя вещами: что такое пин и что такое breadboard.

Пин — что это

Пин — это отдельный контакт, через который идёт ток или сигнал: точка, где провод «встречается» с платой или модулем. У Arduino Uno пины — это дырочки в чёрных гребёнках по краям платы, в них вставляется конец провода. А у некоторых модулей и датчиков в этом наборе (например, у RGB-модуля KY-016 в Проекте 05) пины, наоборот, выглядят как торчащие металлические ножки, и провод надевается на них сверху. Форма разная, суть одна: пин — точка подключения, через которую электричество входит в устройство или выходит из него. Дальше в тексте слово «пин» означает именно это, независимо от формы.

На плате Arduino Uno пины подписаны и разделены по типу:

D2–D13 — цифровые пины: через них Arduino либо посылает сигнал «включено/выключено» (например, зажигает светодиод), либо принимает такой же сигнал (например, узнаёт, нажата ли кнопка).

A0–A5 — аналоговые пины: через них Arduino считывает не просто «да/нет», а число от 0 до 1023 — например, насколько ярко освещён фоторезистор.

Пины с волнистой чёрточкой рядом с номером (~3 ~5 ~6 ~9 ~10 ~11) — цифровые пины с дополнительной способностью выдавать не только «вкл/выкл», но и любое промежуточное значение яркости или мощности. Это называется ШИМ (подробно — в Проекте 05).

5V / 3.3V — пины питания: готовое напряжение для модуля, которому нужно отдельное питание (в отличие от цифровых/аналоговых пинов, ими нельзя «командовать» из кода — напряжение там всегда одно и то же).

GND — общий «минус» платы, к которому подключаются минусы (катоды) всех компонентов схемы.

Breadboard (макетная плата) — что это

Пластиковая панель с сеткой дырочек, которая соединяет детали между собой без пайки: воткнул ножку в дырочку — и она электрически соединена со всем, что воткнуто в дырочки того же ряда. Внутри breadboard дырочки соединены короткими рядами по 5 штук — всё, что воткнуто в один такой ряд, становится одной цепью, как будто спаяно. Отдельно вдоль длинных сторон платы идут ещё две шины, помеченные красной полосой («+») и синей полосой («−» / GND).

!
Главное правило: всегда соединяй GND Arduino с GND (минусом) каждого компонента в схеме. Электричество идёт по замкнутому кругу — оно должно не только «прийти» к компоненту, но и «вернуться» обратно в Arduino. Если минус компонента никуда не подключён, круг не замыкается, и не заработает ничего, даже если «плюс» подключён идеально.
i
На длинных макетных платах шина «+/−» вдоль края иногда бывает разорвана точно посередине. Поэтому если внешне всё подключено верно, а схема не работает — надёжнее вести минусы (катоды) отдельными проводами напрямую на GND Arduino, а не полагаться на то, что боковая шина соединена от края до края.

3.2 — Как определить полярностьЧасть 3

Полярность.

Многие детали в наборе имеют «направление» — важно не перепутать плюс и минус, иначе деталь либо не заработает, либо, реже, может выйти из строя.

Светодиоды

Длинная ножка — анод, «плюс» (сюда приходит ток), короткая — катод, «минус» (отсюда ток уходит на GND). Если ножки обрезаны и одинаковой длины — смотри на сам корпус: плоский срез на ободке (вместо круглого края) — это катод.

Зуммеры

На корпусе обычно отмечен значок «+» — ориентируйся на него, а не на длину ножек (у некоторых зуммеров, включая один из двух в этом наборе, ножки одинаковой длины). В наборе два зуммера: активный (сверху сплошная чёрная «крышечка», только один монотонный писк) и пассивный (видна плата внутри, умеет играть мелодии, нужен для Проекта 04) — не перепутай их между собой.

Датчики на платах

(DHT11, пламя, звук, вода). У них обычно три контакта: S (Signal) — по нему датчик передаёт измеренное значение; VCC — сюда подаётся питающее напряжение, чтобы датчик включился; GND — общий минус. У разных производителей порядок этих трёх контактов на плате может отличаться — всегда смотри на подписи прямо на плате датчика.

i
ИК-приёмник VS1838B: держи его куполом (тёмной линзой) к себе — тогда слева направо контакты идут так: OUT (сигнал), GND (минус), VCC (питание). Сверься с подписями на конкретной плате перед подключением.

Резисторы.

Резистор — маленькая деталь, которая просто мешает току течь свободно, ограничивая его силу, — как узкий участок трубы замедляет напор воды. Без резистора светодиод в большинстве схем этого набора сгорит почти сразу: ему нужен ток намного слабее, чем Arduino выдаёт «по умолчанию», и резистор как раз «придерживает» этот избыток.

В наборе резисторы трёх номиналов (уровней сопротивления) лежат вперемешку в одном пакетике. Отличить их можно только по цветным полоскам на корпусе — их 5 штук. 4 полоски идут плотной группой рядом друг с другом, 5-я (обычно коричневая или красная) — с отступом от остальных; эту дальнюю не считаем, смотрим только на группу из 4.

3.4 — БезопасностьЧасть 3

Безопасность.

Электроника в наборе низковольтная (5 вольт совершенно не опасны для человека), но некоторые ошибки при сборке могут повредить плату или компоненты.

Отключай USB перед тем, как менять схему на breadboard. Пока плата под напряжением, случайное короткое замыкание сорвавшимся проводом может повредить пин или сжечь компонент прямо во время сборки.

Не путай «+» и «−». У большинства датчиков и у моторов есть направление тока; в обратную сторону деталь в лучшем случае не заработает, а иногда может выйти из строя.

Резисторы для светодиодов — обязательны. Без резистора ток через светодиод будет намного сильнее, чем он выдержит, — и он перегорит за секунды.

Не подавай на пины напряжение больше 5 вольт. Пин рассчитан максимум на 5V; выше — можно повредить сам чип платы, а его, в отличие от резистора или светодиода, не заменить.

Мотор, сервомотор и реле подключай только так, как показано в конкретном проекте (обычно через драйвер или отдельное питание), не напрямую от пина — они потребляют намного больше тока, чем пин способен безопасно дать.

Компонент стал заметно горячим? Это ненормально, сразу отключай USB. Так обычно проявляется неправильная полярность или короткое замыкание.

!
Проекты с реле на 220 вольт (сетевое напряжение из розетки) — только для взрослых и под контролем: в отличие от 5V самой платы, 220V уже реально опасно для человека. Без опыта в электротехнике такие подключения лучше не делать самостоятельно.
i
Статика: перед началом работы прикоснись к металлическому предмету (например, к батарее отопления) — это снимет статическое электричество с рук. Не собирай схему на ковре или в шерстяной одежде — так статика накапливается сильнее. Микросхемы 74HC595 и RC522 особенно чувствительны к статике — храни их в антистатическом пакетике, пока не используешь.

Serial
Monitor.

Это справочный раздел: реально понадобится начиная с Проекта 03 («Кнопка»), когда нужно проверять, нажата ли кнопка. Сейчас просто прочитай, что это такое.

Serial Monitor — отдельное окно в Arduino IDE, через которое плата может «писать тебе сообщения» прямо во время работы, а компьютер показывает их как обычный текст. Это главный инструмент, когда код вроде бы правильный, а результат не тот: можно попросить плату «рассказать», что происходит внутри неё, вместо того чтобы гадать. Открывается значком лупы в правом верхнем углу IDE или сочетанием Ctrl+Shift+M.

Через него видно, например: какое число прямо сейчас считывает датчик, какое значение хранится в переменной, нажата ли кнопка — то есть внутреннее состояние программы, которое иначе не увидеть.

в коде
Serial.begin(9600);
Serial.println("текст или значение");

Serial.begin(9600) — включает канал связи между платой и компьютером, пишется обычно один раз в начале программы. Serial.println(...) — отправляет в окно конкретное сообщение, когда до этой строчки доходит выполнение программы.

!
Число 9600 — это скорость передачи данных. Само число не так важно, важно, чтобы оно совпадало в коде и в самом окне Serial Monitor (там тоже можно выбрать скорость внизу справа). Если числа не совпадают — вместо текста будут нечитаемые символы.

Что увидите

Светодиод мигает раз в секунду. Самая короткая программа, доказывающая, что плата, кабель, драйвер и IDE работают.

Теория

Цифровой выход. Пин в режиме OUTPUT бывает HIGH (≈5В) или LOW (0В). digitalWrite(LED_PIN, HIGH) подаёт на D13 пять вольт — ток течёт через светодиод.

Зачем резистор. У светодиода ток ~20 мА. Без ограничения он сгорит. Резистор 220 Ом ограничивает ток: I = (5−2)/220 ≈ 14 мА.

Полярность. Длинная ножка — анод (+), короткая — катод (−). Перевернёте — не загорится, но не сломается.

delay() «замораживает» Arduino на заданное число миллисекунд — чип в это время не реагирует ни на что.

Библиотека vs код. Это разные вещи. Библиотека — доп. набор команд для сложных деталей (LCD-экран, серво, датчики), ставится один раз через Library Manager и нужна не всегда — для этого проекта, например, не нужна вообще («Библиотеки: не требуются»). Код в разделе «Код» ниже — это сама программа для конкретного проекта, её нужно вставлять в IDE всегда, для любого проекта, вне зависимости от того, нужна библиотека или нет.

Подключение

Макетка внутри разбита на маленькие металлические полоски под пластиком — их не видно, но именно они соединяют дырки между собой. Каждая такая полоска идёт вертикально и соединяет 5 дырок одного столбца (одна и та же цифра, буквы A-E — это одна группа, "блок"). Полоска обрывается на бороздке посередине платы, поэтому блок A-E и блок F-J (под бороздкой) между собой не связаны — это как два отдельных дома на одной улице.

Цифры по всей длине платы — это просто номера столбцов, нужны, чтобы ориентироваться и находить нужное место, как номер дома на улице. Буква внутри столбца (любая от A до E, если работаем в верхнем блоке) значения не имеет — хоть A10, хоть C10 — это одна и та же электрическая точка.

Сверху и снизу платы отдельно идут красная (+) и синяя/чёрная (−) полосы через всю длину — это отдельные линии питания, для этого проекта они не нужны, поэтому не трогаем.

  1. Воткните светодиод в макетку так, чтобы обе его ножки попали в два разных столбца одного блока (они и так разъедутся сами — ножки светодиода расположены слишком близко, чтобы попасть в один столбец).
  2. Возьмите резистор 220 Ом (см. 3.3, как отличить). У резистора нет полярности — вставлять можно любой стороной, направление роли не играет.
  3. Один конец резистора вставьте в тот же столбец, где сидит длинная ножка светодиода (анод) — любая свободная буква этого столбца подойдёт. Теперь этот конец резистора "занят" — он в одном столбце со светодиодом.
  4. Другой конец резистора — тот, что пока никуда не подключен, назовём его "свободный конец" — воткните в любой пустой столбец, где раньше ничего не было.
  5. Возьмите провод папа-папа (со штырьками на обоих концах). Один конец вставьте в любую букву того столбца, где сейчас находится свободный конец резистора. Другой конец провода вставьте в дырку на самой плате Arduino, рядом с которой написано «8».
  6. Возьмите второй провод папа-папа. Один конец вставьте в любую букву столбца, где сидит короткая ножка светодиода (катод). Другой конец — в любую дырку на плате Arduino, подписанную «GND» (их на плате несколько, все одинаковые).

Длинная ножка светодиода — плюс (анод), короткая — минус (катод). Резистор обязателен, иначе светодиод сгорит. У резистора полярности нет — переворачивать не страшно. Специально используем D8, а не D13, чтобы внешний светодиод не мигал синхронно со встроенным «L» на плате.

Что увидите

Пока кнопка нажата — светодиод горит, в Serial Monitor печатается сообщение. Отпустили — гаснет.

Теория

Почему нельзя просто подключить кнопку напрямую. Если пин ни к чему не подключён (висит в воздухе), он ловит случайные наводки — как антенна — и digitalRead() может выдавать то HIGH, то LOW без всякой причины, даже когда кнопку никто не трогал.

Решение — INPUT_PULLUP. Это одна строчка кода, которая включает крошечный резистор прямо внутри чипа Arduino. Пока кнопка не нажата, этот резистор держит пин на значении HIGH (как будто "подпирает" его). Когда нажимаешь кнопку — она напрямую замыкает пин на GND, и он становится LOW. Получается наоборот, чем интуитивно кажется: кнопка нажата = LOW, отпущена = HIGH.

Дребезг контактов. Внутри кнопки два металлических контакта при нажатии не касаются друг друга идеально чисто — они несколько миллисекунд дребезжат, как будто быстро стучат друг об друга. Arduino проверяет состояние пина очень часто и может принять этот дребезг за несколько нажатий подряд вместо одного. Команда delay(50) просто говорит "подожди 50 миллисекунд и не проверяй пока" — этого достаточно, чтобы дребезг успел закончиться.

Теория

Что такое tone(). Это команда Arduino, которая заставляет пин «дрожать» — быстро включаться и выключаться много раз в секунду. Если делать это 440 раз в секунду — зуммер издаёт звук, который мы слышим как ноту «ля». Если 262 раза в секунду — это нота «до». Чем чаще дрожание (частота, измеряется в герцах, Гц), тем выше нота.

Пишется так: tone(пин, частота, длительность) — то есть «на этом пине сгенерируй сигнал такой-то частоты и играй его столько-то миллисекунд». noTone(пин) — команда «хватит, выключи звук».

Что такое массив данных. Массив — это просто пронумерованный список значений в одной переменной, а не куча отдельных переменных. Вместо того чтобы писать нота1 = 262, нота2 = 294, нота3 = 330… — все ноты складывают в один список: int melody[] = {262, 294, 330};

У каждого значения в списке есть номер места (индекс), считая с нуля: melody[0] = 262, melody[1] = 294, melody[2] = 330.

Теория (продолжение)

Дальше цикл for просто проходит по списку по одному: бери элемент под номером 0, сыграй его, бери номер 1, сыграй его, и так далее — пока список не кончится. Это и есть «работать с массивом» — не писать команду tone() отдельно для каждой ноты вручную, а один раз написать цикл, который сам проходит по списку нот.

В коде два массива, идущих рядом: melody[] — какая нота (частота), dur[] — как долго её играть. Индекс i одинаковый для обоих, поэтому нота melody[i] и её длительность dur[i] всегда совпадают по номеру места.

Числа длительности (4, 8, 2 и т.д.). Это не миллисекунды, а музыкальные доли: 4 = «четвертная нота» (условно один «шаг» в мелодии), 8 = «восьмая» (в два раза короче), 2 = «половинная» (в два раза длиннее четвертной). Формула 1000/dur[i] переводит это в миллисекунды.

Как самому найти код другой мелодии. Ты не сочиняешь ноты сам — берёшь уже готовый код. Схема такая:

  1. В интернете ищи «arduino tone melody [название песни]».
  2. Люди массово выкладывают готовые скетчи с массивами нот и длительностей под конкретные песни. Названия переменных могут быть любыми — notes[]/durations[], tune[]/tempo[], song[]/noteDurations[] — название значения не имеет, главное распознать по смыслу: массив с числами вроде 262, 440, 523 (частоты в герцах, обычно от 30 до 5000) — это ноты; массив с маленькими числами вроде 1, 2, 4, 8, 16 — это длительности.
  3. Бери оттуда эти два массива, вставляй вместо старых melody[] и dur[] в своём коде (или переименуй переменные под свой код — главное, чтобы имена совпадали с теми, что используются в строке tone(BUZZER, melody[i], d)).
  4. Посчитай, сколько чисел в новом массиве нот, и поменяй это число в строке for (int i = 0; i < 25; i++) — вместо 25 подставь реальное количество нот новой мелодии. Остальную часть кода трогать не нужно, она универсальная для любой мелодии.

Чему научитесь

Раньше пин мог быть только в одном из двух положений: светодиод либо горит, либо нет — как обычный выключатель. Что увидите

Плавно, без единого рывка или мигания — как будто внутри спрятана целая гирлянда, хотя на самом деле это один компонент и четыре провода.

Теория

Пин. Это общее слово для контакта, через который идёт ток или сигнал — точка, где провод «встречается» с платой или модулем. У Arduino Uno пины — это дырочки в чёрных гребёнках сверху платы, туда вставляется провод. А у некоторых модулей, например у KY-016 (о нём ниже в этом же проекте), пины выглядят наоборот — как торчащие металлические ножки, и провод, наоборот, надевается на них сверху. Форма разная, а суть одна: это контакт, через который электричество входит или выходит. Дальше по тексту слово «пин» означает именно это — независимо от того, дырочка это или ножка.

ШИМ (широтно-импульсная модуляция) — способ получить из пина не только «полностью включено» или «полностью выключено», но и любую яркость между ними. Пин очень быстро (490 раз в секунду) щёлкает вкл-выкл, глаз не успевает различить отдельные вспышки и видит ровный приглушённый свет. Чем больше доля времени пин «включён» в каждом таком щелчке — тем ярче. За это отвечает команда analogWrite. Пишется она, например, так: analogWrite(9, 128) — в скобках через запятую два числа: первое — номер пина, на который подаём сигнал (здесь — 9), второе — насколько ярко его зажечь, от 0 (совсем не горит) до 255 (максимальная яркость). Когда в тексте пишут в общем виде analogWrite(пин, число) — слова «пин» и «число» это не конкретные значения, а место, куда каждый раз подставляются свои цифры. Подробно, с примером на выключателе света, — в разделе «Теория (подробно)» ниже.

Сложение цветов. Внутри модуля на самом деле спрятаны три лампочки — красная, зелёная и синяя. Ты не выбираешь, какую из них зажечь, а задаёшь яркость каждой по отдельности, и глаз сам смешивает три цвета в один: красный + зелёный = жёлтый, все три на максимум = белый.

KY-016 — почему всего 4 провода, без отдельного питания (VCC). У обычного светодиода отдельно нужен провод «плюс» (питание) и провод «минус» (возврат тока). У этого модуля четыре пина: R, G, B и GND — то есть три штырька для цвета и один общий «минус». Роль «плюса» здесь взяли на себя сами пины R, G и B: через них одновременно идёт и ток на нужный цвет, и регулировка яркости через ШИМ. Поэтому отдельный провод питания просто не нужен — эту работу уже делают три других провода, а GND просто выводит ток обратно в Arduino.

Теория (подробно)

Что такое ШИМ и зачем он нужен

У Arduino есть проблема: цифровой пин умеет выдавать только два состояния — либо полное напряжение (5 вольт, «включено»), либо ноль (0 вольт, «выключено»). Никакого «среднего» напряжения, вроде 2,5 вольта, напрямую получить нельзя — просто нет такой возможности у пина.

Но нам нужно, чтобы светодиод горел не только «на полную» или «совсем потух», а плавно — вполнакала, на четверть, почти незаметно. Как это сделать, если пин умеет только «да» или «нет»?

Хитрость такая: если очень быстро щёлкать пином вкл-выкл (представь, что ты со скоростью 490 раз в секунду включаешь и выключаешь обычный выключатель света) — человеческий глаз физически не успевает разглядеть отдельные вспышки, они сливаются в одну, и мозг воспринимает это как приглушённый свет. Чем больше доля времени, когда свет «включён» в каждом таком быстром цикле — тем ярче кажется лампочка. Если включено 90% времени цикла — почти максимальная яркость. Если включено 10% — тускло-тускло.

Отсюда и название — широтно-импульсная модуляция (ШИМ): «импульс» — это каждое отдельное включение, «широта» — это то, насколько долго (широко) длится этот импульс внутри цикла, а «модуляция» — просто означает «настройка, регулировка». То есть дословно: «регулировка яркости через изменение длины импульсов включения».

Команда analogWrite(пин, число) — это как раз способ сказать Arduino: «включай этот пин не полностью и не вообще, а вот с такой долей времени». Число задаётся не в процентах, а от 0 до 255 (0 = всегда выключен, 255 = всегда включён, 128 — примерно половина времени, то есть половина яркости).

Зачем это вообще нужно — потому что без этого трюка Arduino мог бы включать светодиод только на полную яркость или гасить его совсем, а с ШИМ можно плавно «подкручивать» яркость, как ручку у обычного диммера в квартире (кстати, домашние диммеры устроены очень похоже — тоже быстро мигают лампочкой, только мы этого не замечаем).

Сложение цветов

У RGB-светодиода на самом деле три отдельных светодиода внутри — красный, зелёный, синий — просто упакованы в один корпус. Ты не выбираешь «какой из трёх зажечь», а выбираешь яркость каждого из трёх одновременно, и глаз смешивает их свет в один цвет. Например: красный на полную + зелёный на полную + синий выключен = жёлтый (это как смешение красок, только со светом). Все три на максимум = белый. Все три выключены = светодиод не горит.

Модуль KY-016 — как через него течёт ток

Представь электричество как воду, текущую по трубе: чтобы что-то заработало, вода должна пройти по замкнутому кругу — вытечь из одного места и вернуться обратно.

У модуля KY-016 три отдельных светодиода (красный, зелёный, синий) внутри одного корпуса, и у каждого из них есть свой «вход» — это и есть три пина R, G, B. А «выход», куда ток возвращается после того, как прошёл через светодиод и заставил его светиться — один общий провод GND, одинаковый для всех трёх цветов.

Получается: Arduino подаёт ток через пин R (или G, или B) → ток проходит через нужный светодиод внутри модуля, заставляя его светиться → и возвращается обратно в Arduino через провод GND. Резистор, который ограничивает силу тока (чтобы светодиод не перегорел от слишком сильного напряжения), уже встроен в сам модуль — отдельно покупать и подключать его не нужно.

Отдельный провод питания (обычно подписывается VCC) тут не нужен, потому что каждый из пинов R/G/B сам одновременно и подаёт питание на светодиод, и регулирует его яркость через ШИМ — две задачи в одном проводе.

Если не работает

Цвет резко вкл/выкл +
Плавную регулировку яркости (ШИМ) умеют делать не все пины Arduino — только те, рядом с номером которых на самой плате нарисована тильда ~ (в этом проекте это D9, D10, D11). Если провод от R, G или B случайно попал на пин без тильды, этот пин умеет быть только полностью включён или полностью выключен — «среднего» там просто физически нет, поэтому вместо плавного перелива получится резкий щелчок вкл/выкл. Проверь, что все три провода от модуля воткнуты именно в пины с тильдой, и что номера этих пинов совпадают с теми, что указаны в начале кода (const int R=9, G=10, B=11;).
Один цвет не работает +
У этого модуля нет отдельного провода питания — каждый цвет получает ток через свой собственный пин (R, G или B), а не через общий провод для всех трёх. Значит, если плохо подключён именно один из этих трёх проводов, сломается ровно один цвет, а остальные два будут работать нормально — это нормальная логика для такой схемы, а не что-то странное. Проверь провод именно того канала, который не горит: плотно ли он воткнут в модуль и в Arduino, и в тот ли пин, что указан в коде.
«Красный» горит синим +
Сама схема исправна, просто провода R, G и B перепутаны местами — например, провод, который физически идёт от контакта R на модуле, воткнут в пин Arduino, который код считает пином B. Тогда команда «зажги красный» на самом деле подаёт сигнал туда, где физически подключён синий канал, — вот и горит не тот цвет. Исправить можно любым из двух способов: либо переткнуть провода так, чтобы R, G, B на модуле физически шли на те же пины, что и в коде, либо проще — поменять номера пинов местами в строке const int R=9, G=10, B=11; в начале кода, под то, как уже подключено у тебя.
Тускло во всех цветах +
GND — это общий обратный провод сразу для всех трёх цветов: через него ток возвращается в Arduino после того, как прошёл через любой из R, G, B. Если этот провод подключён плохо (не до конца воткнут, шатается), току труднее замкнуть цепь через любой канал — поэтому тускнеют сразу все цвета, а не один. Проверь именно чёрный провод (GND) с обеих сторон — на модуле и на Arduino.

Подключение

Фоторезистор без полярности (как резистор), но тут он с резистором 10 кОм образует «делитель напряжения» — две детали подряд, между ними снимается сигнал на A0.

  1. Один вывод фоторезистора → в столбец, соединённый проводом с 5V.
  2. Другой вывод фоторезистора → в новый столбец. Этот же столбец соедините проводом с A0.
  3. В тот же столбец — один конец резистора 10 кОм. Другой конец → в GND.
  4. Светодиод — как в Проекте 01, но анод через резистор 220 Ом идёт на D9 (не D13).

const int BRIGHT = 800, DARK = 100;  // откалибруйте

void setup() {

void loop() {

Чему научитесь

Управлять шаговым мотором через ULN2003, работать с Stepper.h, считать шаги и переводить их в градусы.

Компоненты
  • Arduino UNO ×1

  • Драйвер ULN2003 ×1
  • 3 кнопки ×3
  • Breadboard ×1

Что увидите

Три кнопки: по часовой на 45°, против на 45°, возврат в начало. Команда «a 90» в Serial поворачивает на точный угол.

i
Шаговый vs серво: серво — 0–180° с обратной связью. Шаговый — любой угол, любая сторона, без ограничений. 28BYJ-48 ≈ 2048 шагов/оборот (~0,18°/шаг), но медленный.

Теория

Шаговый мотор делает один фиксированный микроугол на каждый импульс. Считая импульсы, точно знаешь угол — без датчиков.

28BYJ-48 со встроенным редуктором 1:64 (~4096 шагов на вал; в Stepper.h берём 2048 на оборот ротора). Цена за точность — медленный и потребляет ток даже стоя.

ULN2003 — 7 транзисторных ключей: Arduino не питает обмотки напрямую, драйвер берёт слабый сигнал и переключает мощные ключи.

Код

Arduino · C++
#include <Stepper.h>

const int STEPS_PER_REV = 2048;
// ВНИМАНИЕ: порядок IN1, IN3, IN2, IN4 (не 1,2,3,4!)
Stepper motor(STEPS_PER_REV, 8, 10, 9, 11);

const int BTN_CW = 2, BTN_CCW = 3, BTN_HOME = 4;
long currentPos = 0;

void setup() {
  pinMode(BTN_CW, INPUT_PULLUP);
  pinMode(BTN_CCW, INPUT_PULLUP);
  pinMode(BTN_HOME, INPUT_PULLUP);
  motor.setSpeed(10);  // об/мин (макс ~15)
  Serial.begin(9600);
}

void stepBy(int steps) {
  motor.step(steps);
  currentPos += steps;
  Serial.print("Pos: "); Serial.print(currentPos);
  Serial.print(" -> Angle: ");
  Serial.println((currentPos * 360.0) / STEPS_PER_REV);
}

void loop() {
  if (digitalRead(BTN_CW) == LOW) { stepBy(STEPS_PER_REV / 8); delay(200); }
  if (digitalRead(BTN_CCW) == LOW) { stepBy(-STEPS_PER_REV / 8); delay(200); }
  if (digitalRead(BTN_HOME) == LOW) { stepBy(-currentPos); delay(200); }
  if (Serial.available()) {
    char cmd = Serial.read();
    if (cmd == 'a') {
      int targetAngle = Serial.parseInt();
      long targetSteps = (long)targetAngle * STEPS_PER_REV / 360;
      stepBy(targetSteps - currentPos);
    }
  }
}

5.3 — Частые вопросы

Можно оставить проект собранным? +
Да, пока подключено питание. Но для следующего проекта те же компоненты придётся разобрать.
Как питать без компьютера? +
Батарейкой 9V через DC-разъём (есть в наборе) или зарядником с USB-выходом.
Сколько проектов одновременно? +
Простые (LED, кнопка) — 2–3 сразу. Сложные с LCD/клавиатурой занимают почти все пины.
Можно без реального Arduino? +
Да — онлайн-симулятор Tinkercad: собирайте схемы и загружайте код виртуально.
Код не загружается +
Проверьте плату и порт; закройте Serial Monitor; смените USB-порт и кабель; переустановите CH340.
